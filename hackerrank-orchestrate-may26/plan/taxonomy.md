# Taxonomy and Product Areas

Definitive structure for classifying support tickets across HackerRank, Claude, and Visa.

## HackerRank Taxonomy
- **screen**: Online assessments, proctoring, test creation, proctoring settings, candidate reports.
    - *Keywords:* assessment, test, proctoring, score, candidate, invite, re-invite, duration, variant.
- **interview**: Live coding interviews, technical interview settings, scorecards, whiteboards.
    - *Keywords:* live, coding, whiteboard, scorecard, audio, video, interviewer, interview session.
- **community**: Developer profiles, contests, public certifications, developer learning.
    - *Keywords:* profile, badge, contest, leaderboard, developer account, public profile.
- **skillup**: Employee learning platform, skills tracking, role certifications, manager dashboards.
    - *Keywords:* learning, employee, proficiency, badge, skill profile, manager, tracking, certification.
- **integrations**: ATS integrations (Greenhouse, Lever), SSO configuration, SCIM provisioning.
    - *Keywords:* ATS, Greenhouse, Lever, SSO, SAML, Okta, SCIM, API integration, webhook.
- **general_help**: Platform maintenance, release notes, contact information, GDPR.
    - *Keywords:* maintenance, contact, support, release notes, GDPR, privacy, nyc ai law.
- **settings**: Admin settings, team management, billing, user account preferences.
    - *Keywords:* billing, invoice, subscription, team, user, password, delete account, card update.

## Claude Taxonomy
- **account_management**: Billing, subscription management, security, login issues.
    - *Keywords:* billing, pro, max, team, enterprise, login, password, delete account, refund, invoice.
- **conversation_management**: Chat features, artifacts, renaming conversations, sharing chats.
    - *Keywords:* chat, history, archive, artifact, delete chat, share, conversation, organization.
- **product_usage**: iOS/Android apps, Desktop app, Web platform, accessibility.
    - *Keywords:* mobile, app, desktop, ios, android, web, interface, UI, buttons, layout.
- **api_console**: API development, keys, rate limits, Workbench, Console access.
    - *Keywords:* API, key, console, rate limit, tokens, context window, workbench, prompt.
- **claude_code**: Claude Code CLI usage, analytics, command line interactions.
    - *Keywords:* CLI, terminal, command, analytics, claude code, install.
- **privacy_legal**: Data privacy, Terms of Service, content filtering, safety.
    - *Keywords:* privacy, content filtering, legal, safe, blocked, copyrighted, TOS, safety.
- **bedrock**: Amazon Bedrock integration, AWS specific usage.
    - *Keywords:* AWS, Bedrock, Amazon, model, integration.

## Visa Taxonomy
- **consumer_support**: Cardholder help, lost/stolen cards, travel services, rules.
    - *Keywords:* card, stolen, lost, travel, atm, locator, exchange rate, cardholder, rules.
- **small_business**: Merchant support, fraud prevention, dispute resolution, business tools.
    - *Keywords:* merchant, business, fraud, dispute, chargeback, transaction, limit, security.
- **travel_support**: Travelers cheques, global assistance, emergency services.
    - *Keywords:* travelers cheques, citicorp, stolen, refund, emergency cash, global assistance.

## [WARNING] Terminology Overlaps (Confusion Risks)
- **"Screen"**:
    - *HackerRank:* Refers to **Assessments** (the "Screen" product).
    - *Claude/Visa:* Refers to a **device screen** or UI element.
- **"API"**:
    - *HackerRank:* Refers to **integrations** with ATS or internal systems.
    - *Claude:* Refers to the **core product** for developers (Claude API).
- **"Enterprise"**:
    - *HackerRank:* Refers to **HackerRank for Work** large-scale plans.
    - *Claude:* Refers to the **Claude Enterprise** plan with 500K context.
- **"Refund"**:
    - *HackerRank:* Usually involves **subscription** overcharges or missing services.
    - *Claude:* Often related to **Pro/Max** plan cancellations.
    - *Visa:* Usually refers to **Travelers Cheques** or merchant charge reversals.
- **"Integrations"**:
    - *HackerRank:* Refers to **ATS** and workflow tools.
    - *Claude:* Refers to **Connectors** (e.g., Google Drive, GitHub) or **Amazon Bedrock**.
- **"Pro"**:
    - *Claude:* A specific **individual paid plan** (Claude Pro).
    - *HackerRank:* Sometimes used informally for **Professional** services or advanced features (but not a specific plan name).
